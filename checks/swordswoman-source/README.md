# 女侠桌面伙伴

本地新增选项 `swordswoman`，默认名称「女侠」。后台可改名、启停、排序及逐项配置动作；不修改已有用户选择，也不替换默认小姑娘。

## 素材

- 使用内置 image_gen 生成，28 张独立透明 PNG，每张只有一个完整人物。
- `prompts.json` 保存逐帧提示词与原始生成路径；`frame-0.png` 至 `frame-27.png` 为项目内保留的原图。
- `actions.json` 定义 7 种状态、21 个动作组合，跑步含不同速度组合。
- `contact-sheet.png` 是校对总览，不用于运行时裁切。
- `bounds.json` 记录透明边界与统一落脚基线。
- 运行素材在 `dist/assets/site-icons/pet-swordswoman-frame-{0..27}.png`；后台预览使用同一份输出。

动作包括盘腿抱剑、闭目静坐、转头、枕手扣笠休息、翘腿伸展、拔剑归鞘、持剑练习、小跑、疾跑、轻跳及轻功滑行。

## 继承规则

共用原有主题落点、六个地面候选点、路径选择、重力与碰撞、拖拽优先级和释放后一分钟暂停。共用后台安静/活泼/兴奋的自然陪伴与互动回应时长。女侠动作开关使用独立的 `swordswoman-` 前缀，不受小姑娘动作开关影响。

## 验证

- 28 张素材透明边界校验；完整人物含剑、斗笠、披风与脚部，运行帧 512 × 512。
- 前台七种状态、后台别名、动作禁用、整体开关、原默认保持与账号选择恢复通过。
- 女侠漫游中拖拽、落地后拖拽、释放位置保存、一分钟暂停、主题切换与刷新通过。
- 原有小姑娘动作回归通过。
- 后台七组 21 项预览、悬停播放、开关保存、全局时间保存与窄屏抽屉通过。
- 配置兼容与时长测试 10 项通过，后台生产构建通过。
