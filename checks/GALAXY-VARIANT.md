# 银河与行星试版

仅调整原行星轨道 / 场景星系。星际漫游和 2D 布局保持原逻辑。

- 新版入口：3D → 银河与行星。
- 当前空间为银心，旋臂展示当前空间下的场景；场景 → 分组、分组 → 网址仍为太阳系圆盘，每次仅渲染下一层。
- 添加入口在最内侧轨道，只有一项，沿用原新增操作。
- 放大到可读尺寸、星球下方没有其他节点遮挡时显示分组 / 网址统计。
- 保留滚轮指针锚定、Shift 平移、空白拖动旋转、节点排序、轨道调整与聚焦复位。

旧版对比：打开 `http://127.0.0.1:4318/?atlas-orbits=classic`，进入图谱后可选原来的「行星轨道」「场景星系」。该地址保留旧轨道、卫星和添加入口逻辑。

修改前完整文件保存在 `baselines/atlas-galaxy-before-20260917/`。银河旋臂使用独立的 `solar:galaxy:` 轨道保存键，旧版圆环配置继续保留。未删除或迁移任何空间、场景、分组和网址数据。
