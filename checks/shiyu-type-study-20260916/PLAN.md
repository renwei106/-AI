## 建议调性

安静、有书卷气、带一点自然的温度；字形舒展，笔画清楚，细节克制。让「拾起喜欢，安放日常」读起来既有分寸，也有亲近感。

当前官网是墨绿黑背景、暖白与淡金文字、粒子光影与短句叙事。适合让标题承担品牌性格，正文与交互保持清晰。在深色屏幕上不宜只追求极细笔画；字重、对比度与手机阅读需要一起评审。

### 推荐组合

- 品牌与叙事标题：优先继续细化 A。
- 正文、按钮、导航、小英文与小数字：采用 C 所代表的清晰无衬线思路，用常规字重；不是将 Light 字重直接铺到全部小字。
- 情绪短句：若偏爱 B，可作为品牌表达的另一个方向再做一轮比较，暂不引入三套主字体同时竞争。
- 展示数字与功能数字分工：海报日期可与展示英文协调；计时、价格、序号则优先清晰和数字宽度稳定，正式落地时验证等宽数字特性、标点与对齐。

## 字体到底怎样生成

字体文件可以理解为「字符到字形的字典」，还包括字宽、间距、字重及排版规则。浏览器拿到文字后，从字库中找到相应字形并绘制。

**自动适配意味着自动调用已有字形，不意味着自动发明缺失字形。** 如果字库没有某个汉字，浏览器可能改用后备字体显示，字形风格就可能发生变化。字符的字体选择可以逐字回退，参见 [MDN font-family](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-family)。

不同交付层级有不同工作量：

1. **品牌字体体系**：组合成熟的中英文字库，制定字号、字重、行距、字距、标点、数字和后备字体规则。中文内容使用字库中已完成的字符，不需要我们重画全部汉字。系统性搭配可以形成品牌气质，但不等于字体独占。
2. **专属品牌字样**：单独设计「拾隅」以及确认后的英文品牌字样，交付矢量字标。只覆盖这些字，不能把任意新句子都变成同样的原创字体。
3. **在许可允许的字库上定制**：结合允许修改的基础字库调整关键字形或整体规则。修改、命名、分发与版权标注遵守对应许可；不能把改名当成原创或独占。
4. **完整原创字库**：先定义字符覆盖范围，再设计笔画与部件、组字、逐字修正，并处理标点、拉丁字母、数字、字距、多字重及屏幕表现。可以复用部件并借助工具提高效率，但最终支持的每个字符都需要正确字形与质量检查；不必覆盖所有 Unicode 汉字，却必须明确承诺支持哪些字。

网站的中英数不必放进一个物理字体文件。可以用中文与拉丁字库搭配成一套视觉体系，匹配字高、粗细、基线和标点。也不建议仅凭几张效果图就合并、重命名成可分发字体。

## 确认方向后再做什么

1. 选 A、B、C 中的一版，或明确「A 的中文 + C 的英文」等组合，先完成一次精修样张。
2. 用「拾、隅、永、国、静、风」等代表字细化疏密、转折、收笔；用大小写、数字与标点检查协调性。针对品牌字样，可探索「拾」更舒展、「隅」密集处更透气的细节，而不是只增加字距。这些是下一阶段探索，当前样张尚未改形。
3. 确认是否需要独立设计字标，还是确实需要全新可安装字库。先把使用场景与覆盖范围定下来。
4. 如选择接入官网，保留现有页面与交互，仅处理字体相关代码。分别核对桌面和手机、深色与浅色场景、小字号与中英文混排。
5. 正式接入使用本地托管的网页字体，按需分包/子集化、缓存与后备字体，避免依赖访客电脑已安装的字体。固定官网文案可以生成小型子集；新增文案必须更新子集，用户输入内容应采用更完整的字库或自动分包方案。

Google Fonts 的 [CSS API 文档](https://developers.google.com/fonts/docs/css2) 说明可按指定字重和文字内容请求字体子集。这是在已有字形中选择需要的部分，并不是生成新字形。

## 本轮交付与限制

- `index.html`：可切换三版与深浅字样的独立预览；桌面与手机官网截图随选项变化。
- `a-board.png`、`b-board.png`、`c-board.png`：可单独查看的方向板，含中英数样本及现有官网应用效果。
- `comparison.png`：同尺寸三方向对照总览。
- `captures/original-*.png`：当前官网原字体对照；`captures/a-*.png` 等：只在浏览器临时替换字体的截图。
- `fonts/`：样张所用字体及原许可；`manifest.json` 记录下载来源、文件大小和哈希。
- `verification.json`：浏览器实际使用字体、视口及交互检查记录。

本轮宋体、黑体与拉丁字体按样张字符做了子集；霞鹜文楷使用上游完整 TTF，仅用于本地评审。演示资源不是最终生产包，不建议直接上线。效果图验证的是当前浏览器下的排版方向，不代表所有设备、所有字符或繁体场景都已经验收。
