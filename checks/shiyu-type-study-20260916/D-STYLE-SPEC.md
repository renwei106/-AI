# 拾隅 D「游风」字体风格与识别规范

版本：1.0 / 2026-09-16

## 目标

D 的个性来自轻微的书写动作，不来自难认、错认或过度简化。所有字形遵循同一顺序：**标准结构 → 清楚识别 → 轻度个性 → 句子节奏**。

「起」不是需要单独补丁的特殊字，而是暴露了一类系统性风险：主部件被压缩、连接关系被改写、连续笔势吞掉了关键结构。以后生成任何新字，都要在进入样张前拦截这类问题。

## 风格边界

### 必须保留

- 保留现代简体中文通行字形的部件组成。不能少部件、换部件或把两个部件连成另一个形状。
- 保留部件之间的关系：左右、上下、包围、穿插和主次重心必须清楚。
- 保留决定识别的关键笔画与空间。走字底、口框、折角、交叉点和封闭空间不能被笔势吞没。
- 保留常用字的第一眼轮廓。脱离上下文单独出现时，也应能认出。
- 相同部件遵循相同的基础写法。例如同一个偏旁不能在不同字里忽然换成另一套造型逻辑。

### 可以个性化

- 收笔可略微拉长、变圆或带一点提按感。
- 横竖长度可以小幅错落，让整行不显得机械。
- 重心允许轻微上提或偏移，但不能改变部件关系。
- 转角可从机械折角变成柔和转折，但转折位置必须保留。
- 简单、开阔的字可多一点动作；复杂、密集和易混淆的字自动收敛。

### 禁止

- 禁止草书式省笔、借笔和大范围连写。
- 禁止同时修改一个字的结构、倾斜、笔画数量和重心。
- 禁止为了“艺术感”压扁偏旁、合并交叉点或封死负空间。
- 禁止借用假名感、符号感或陌生装饰替代汉字部件。
- 禁止依赖上下文猜字。句子能猜出来，不代表字形合格。
- 禁止在网页里用另一套字体临时替换失败字符；失败字应回到生成阶段重做。

## 个性强度分级

| 字形类型 | 个性强度 | 处理规则 |
| --- | --- | --- |
| 简单、开阔、笔画少 | 轻至中 | 可以调整一处长笔画或收笔，结构不动。 |
| 常规左右或上下结构 | 轻 | 只选择收笔、长度、弧度中的一种变化。 |
| 笔画密集、部件相近 | 极轻 | 优先保持标准骨架，仅统一粗细和末端语言。 |
| 容易与其他字混淆 | 极轻 | 关键部件和负空间完全按清楚字形处理，不追求夸张。 |
| 小字号正文与功能文字 | 无展示变形 | 使用拾隅正文阅读字体，不使用 D 展示字形。 |

这套分级按结构风险自动决定个性强度，不建立“看到哪个字不顺眼就换字体”的例外清单。

## 生成流程

1. **建立标准骨架**：先用清楚的通行字形确定部件、关键笔画、负空间和重心。
2. **标记识别锚点**：列出不能移动、删除或合并的笔画与交叉关系。
3. **选择一个个性动作**：每个字只优先采用一种变化，例如收笔略长、局部弧度或轻微重心变化。
4. **按风险自动收敛**：复杂字、易混字、小字号字减少变化；简单字才允许多一点动作。
5. **回到无上下文单字检查**：不看词组，确认单字仍能立即读出。
6. **进入句子检查**：确认字与字之间节奏协调，没有某个字突然像另一套文字或符号。
7. **不合格则重做字形**：回到标准骨架重新生成，不在应用层拼接其他字体。

## 验收标准

### 单字识别

- 将字从词组中单独拿出，在不提示读音和上下文时检查。
- 24、32、48、72 像素四档都要检查；24 像素时关键结构不能糊成一团。
- 至少由 5 名熟悉简体中文的阅读者做盲测，4 人以上在 1 秒内正确识别才通过。
- 若读者需要依赖上下文、猜偏旁或多看一眼，该字退回重做。

### 字形结构

- 关键部件、关键笔画和主要负空间必须全部存在。
- 任何连笔都不能跨越部件边界并制造新轮廓。
- 与标准骨架相比，每个字原则上只出现一种主要个性动作。
- 同一偏旁在整套字形中保持一致的结构规则和笔触语言。

### 句子与品牌场景

- 用「拾隅」「拾起喜欢，安放日常」「万千世界，始于一点喜欢」作为固定回归样句。
- 补充包含左右、上下、包围、走之、心底、口框等不同结构的测试句。
- 分别放到浅色样张、官网深色首屏和手机尺寸检查。
- 大标题可以使用 D；正文、导航、按钮、日期和长段内容使用清晰阅读字体。

## 中文、英文和数字的一致性

- 中文承担品牌动作，英文和数字只做轻微呼应，不模拟毛笔或草写。
- 英文字母保持标准字母骨架，个性主要来自曲线、字面宽度和衬线节奏。
- 数字 `0/6/8/9`、`1/7`、`3/8` 必须有明确区别；时间、日期和金额优先清晰。
- 中英文混排时，以视觉字高和粗细协调为准，不强迫三者拥有相同笔触。
