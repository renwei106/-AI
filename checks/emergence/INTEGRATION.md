# 涌现主题接入

本地完整主站预览：http://127.0.0.1:4328/ 。从左上角“拾隅”的主题列表选择“涌现”。4327 仍是独立原型。

后台：http://127.0.0.1:5175/apps/shiyu/personalization/themes 。涌现卡片可开关、排序、设置别名；设置抽屉包含场景开关、默认场景、允许用户调整参数以及各场景完整默认参数。抽屉“应用到列表”后，通过“保存并同步前台”持久化。

## 接口与优先级

- 沿用主题 ID `emergence` 的现有目录、套餐、体验时长与权限机制；没有新增免费权限或修改会员方案。
- `GET/PUT /api/shiyu/operations` 新增 `emergenceContent`，包括 `defaultScene`、`allowCustomize` 和 `scenes[id].enabled/defaults`。PUT 沿用拾隅管理员权限，保存到现有 operations 存储文件，其他配置保持不变。
- 配置至少开放一个场景，默认场景必须已开放；数值限制及繁衍上限在服务端校验。水滴不在场景目录中。
- 首次进入和“恢复默认”读取后台参数；允许自定义时，账号隔离的浏览器参数优先。关闭自定义后使用后台参数；关闭场景后不能继续选择它。页面再次获得焦点时重新读取配置。
- 首次配置读取失败时显示重试，不自行绕过后台创建场景。切换主题、退出首页或切换账号时清理动画及事件。

## 文件与验证

- 前台 `dist/emergence-theme.js` 同步注册主题，`dist/assets/emergence/shell.js` 管理 UI 与配置。原型和主题使用相同的模拟引擎与规则。
- 后台 `shiyu-emergence-config.ts` 校验配置，`membership/emergence-scenes.json` 对应前台规则字段；`src/ShiyuEmergenceContent.tsx` 使用现有抽屉。
- 后续修改规则字段时须同步前后台 schema，并执行 `node checks/emergence/verify-contract.cjs`。
- `verify-integration.cjs` 验证主题入口、场景切换、配置优先级、长按加速、权限、清理和响应式布局；测试权限仅注入测试浏览器。
- `verify-admin-integration.cjs` 验证后台编辑与保存请求，拦截 PUT，不改实际配置。后台 `shiyu-emergence-*.test.ts` 在隔离临时文件中验证真实持久化与权限。
- 前后台基线分别在 `baselines/emergence-integration-before-20261003` 和后台 `.local/emergence-integration-baseline-20261003`。

本轮仅本地实现和验证，未发布、未修改线上数据或版本。将来发布须同时包含后台配置模型与前台资源，先确认环境/接口及版本号，再按既有上线记录和审批流程执行。

## 2D / 3D

两个场景的“显示维度”使用现有 `depth` 配置字段：`flat` 为 2D，`depth` 为 3D；原“轻景深”升级为真实三维模拟。后台可保存每个场景的默认维度，前台按原有配置优先级读取。

3D 使用三维位置、速度和周期边界；鸟群与鱼群的邻居计算、捕食和繁衍考虑前后距离，宇宙引力在三维空间计算。Canvas 绘制透视投影与按距离排序的几何面。左右拖动可旋转整圈，上下拖动调整俯仰；3D 中鼠标专用于观察，不触发驱散、吸引或长按加速。2D 保留既有交互。拖动支持指针捕获、失焦/取消清理，暂停时仍可旋转。

`verify-3d.cjs` 验证三维邻居、捕食、繁衍、边界与实际拖动；`verify-integration.cjs` 同时检查主站两个场景的维度切换。

## 群游合并与面板

鸟群和鱼群合并为“群游”，内部保留 `birds` ID；形状可选鸟形、鱼形、三角、短线与圆点，捕食和繁衍共用配置。鱼形沿用水流运动规则。旧 `fish` 选中状态与参数迁入群游，后台旧场景开关合并时保留任一已开放的群体场景；两个均关闭则群游仍关闭。返回和保存的新配置仅包含 `birds`、`cosmos`。

主站设置面板使用预览卡片、3px 轨道、浅底圆角分组与半透明毛玻璃。面板内滚轮/触摸滚动不再触发主站翻页手势，底部三个操作保持固定。左侧标题按场景更新，同时保留用户自行配置的标题。`verify-panel.cjs` 检查旧设置迁移、滚动、按钮、形状、文案及三个视口的明暗布局。
