# 互动视频主题 · 本地实现

- 预览：http://127.0.0.1:64559/，主题 ID `forestCompanion`，主题权限继续由现有后台控制。
- 管理入口：拾隅后台 → 内容中心 → 主题板块 → 主题 → 森间绒伴设置 → 内容 · 平台视频。
- 平台内置：森间绒伴、毛线女孩（来自用户提供的新版.mp4）。不修改默认主题；视频列表第一项作为没有保存选择时的默认素材。
- 平台上传：MP4，2～15 秒，30 MiB，最长边 3840 像素，最多 8 项。后台支持改名、前移/后移、移除、反向映射和个人上传开关。上传后先进入草稿，“应用到列表”后再“保存并同步前台”。配置写入既有 operations 存储，素材放入后台本地持久化目录。
- 个人上传：MP4，2～10 秒，20 MiB，最长边 3840 像素，每账号最多 3 项。视频及中点封面保存在 IndexedDB 的账号键下，选择单独按账号保存；不上传云端、不放入账号同步数据。清理浏览器网站数据后素材会丢失；不同浏览器、设备或站点域名不共享本地数据。
- 时轴：`target = (duration - 1/30) * clientX/innerWidth`，比例限制在 0～1；反向素材取 `1-ratio`。时长不会改变操作方式。全程暂停，无 autoplay / play 调用，RAF 合并输入，单次 seek 只保留最新目标。
- 手机、减少动态效果时显示中点封面；共享搜索、导航和其他主题保持原有行为。
- 校验：浏览器测试覆盖账号隔离/恢复、刷新、本地视频零上传、大小及时长限制、配置开关、快速切换、均匀映射、手机与减少动态效果。旧主题测试覆盖暂停标志、边界、窗口缩放、可见性、失败封面、卸载和主题后台开关；后台测试覆盖视频验证与配置读写持久化。现有 base 主题浅深色样式对照相同。
