# 我的小记：斜向卡牌与纸团

本次仅替换“我的小记”弹窗内容。保留已有纸质封面、虚线内框、标题／摘要、字体与项目主题色，将封面改为竖向斜列。入口、登录、收藏、待办和现有小记存储位置不变；没有修改后台模块开关或发布线上。

  - `dist/assets/memo-paper/carousel.js` 与 `dist/memo-paper.css` 接入原版相对位置、层级、800% / 200% 位移、120 度旋转和 0.8 秒缓动。根据任意小记数量使用十张卡的空间间距，移动端缩小间距。
  - 按需求把滚轮进度适配为每格切一张，连续滚动不等待动画完成；触控板小增量累计后切换。鼠标／触屏横拖保留原版拖动方向。真正改变选中项时调用主站原有 `playCardSound()`，与“我的常用”一致。
  - [CodePen 公开 Pen 的 MIT 说明](https://blog.codepen.io/documentation/licensing/)。
- [Paper Crumple](https://github.com/item-develop/paper-crumple-demo)，nagasawa / ITEM Inc.，MIT。

  - `paper.js` 保留网格构建与插值，将示例广告纸面换为纯纸。展开后叠加 HTML 只读预览，捡回后使用独立纸张编辑。

来源与 SHA256 保存在 `SOURCES.json`；作者许可及 Three.js / cannon-es 声明随运行时资源保留。

## 卡牌、垃圾桶与归档

正常小记为斜向卡牌，首张固定为新增卡牌，默认聚焦第一条已有小记。滚轮、左右键或横向拖动可快速翻阅，点击卡牌展开编辑，悬停显示“丢弃”；触摸设备在当前卡牌上直接显示丢弃入口。编辑纸张从被点击卡牌的实际位置与角度整体放大，保留虚线内框，标题和正文没有输入框边缘或焦点描边。获得焦点后隐藏对应占位文案，光标跟随明暗主题的前景色，与纸面保持对比。编辑期间隐藏模块标题、视图切换、底部按钮及主题拉绳，并隔离背景操作。右上角只保留“关闭”，点击关闭或纸面外蒙层都会保留修改并收起；Escape 不退出。动画回到原卡牌位置，原翻阅位置不变。返回时先更新底层卡牌，蒙层淡出后保持透明直到卸载，并将编辑纸张渐隐交接给卡牌，避免蒙层动画结束复原造成闪动。

标题最多 20 字，不显示标题字数提示；正文最多 300 字，保留正文计数。按可见字符计数，支持中文输入法和表情；粘贴或插入受限时保留已有尾部文字。编辑过程使用内存草稿，点击蒙层或关闭后写入原账号存储。历史超长内容不会在打开时截断，未修改可直接收起，修改后须精简到限制以内再保存。废纸团预览仍可点击纸面或空白处收起。

左上角四角星悬停即打开横排颜色菜单：第一项为带循环箭头的圆形“跟随主题”，后面依次为灰、红、绿、橙、蓝、紫。未标色的旧小记和新建小记默认跟随统一 `--accent`；已明确选择的固定颜色保留。点击色点立即改变该小记的星标与卡牌底色。触摸设备可点星标展开；键盘聚焦星标后按下箭头进入色点，Escape 关闭。颜色只写入当前小记的 `color` 字段，随原有账号存储保存，不改变全局主题。上一版颜色在显示时映射到对应色域，无需重写历史数据。

打开编辑纸张时只聚焦容器，标题和正文均没有初始输入光标，点击字段或键盘 Tab 后才输入。卡牌左下角的显示序号按当前列表位置从后往前连续计算：最后一张始终为 01，倒数第二张为 02。丢弃、捡回和新增后都会补齐序号，不留空号。底部只显示当前正常卡牌数量，不包含新增入口、垃圾桶记录或历史已删除记录，翻阅不改变数量。原有 `number` 与 `library.lastNumber` 字段仅保留添加顺序和历史数据兼容，不再作为卡牌展示序号或当前数量；未手动排序时仍按添加先后从新到旧排列。长按普通小记约 300 毫秒后可拖动排序，浮起卡牌保持抓取位置并实时跟随指针，相邻卡牌平滑移入空位。拖至左右边缘会继续翻到前后位置；松手后在原账号 `library.cardOrder` 中保存顺序，刷新后保留，既有内容与添加编号不变。Escape、失焦或指针取消会还原本次拖动。短拖仍用于翻阅；“写下一笔”不参与排序，保持第一位，新增小记排在已有小记之前。

首页“我的一隅 → 小记”打开此界面，保留原登录与账号数据流程。底部关闭复用“我的常用”的入口迁移与返回动效；右上角复用原拉绳操作，提供主题、主颜色、明暗切换，左上角“我的小记”也能切换主题。其他模块保持原有两个拉绳。左下角不显示操作提示或独立体验文案。首页菜单异步收到模块配置后，点击、滚轮和选中位置同步使用当前可见模块，避免显示“小记”却打开其他模块。

只有已丢弃小记变成纸团，隐约留在卡牌背景中。纸团沿用对应卡牌的颜色，使用淡色纸面与更明显的同色色带。标题按短行分布在原模型 UV 上的 canvas 纹理中，随 VAT 网格一起弯折、遮挡，在不同折面上露出片段；保留编号，不添加悬浮标题标签。展开预览时不重复叠印标题，仍显示完整的只读内容。跟随主题的纸团也会同步换色，更新纹理不重置位置。

第一次点击背景纸团先弹跳切换到垃圾桶视图，第二次点击才展开为纯文本预览，不提供输入框或编辑按钮。垃圾桶画布上移到视图标签附近，横向占满屏幕；鼠标移动或悬停不会带动任何纸团。按住某个纸团约 220 毫秒后可拖动它，松开即结束拖动，保留原物理落下／抛掷；从空白处按下不能途中抓取纸团，短按单击仍用于预览。鼠标与触屏统一采用按住后拖动。点击预览纸面或空白处重新揉回纸团；只有点带回转箭头图标的“捡回来”恢复到卡牌后才能编辑。日期与底部操作处于同一对齐行。原来的卡牌在“我的小记”下方收成紧密的一摞，点击卡牌堆或 tab 可回到小记。切换时以卡牌当下的位置、角度和缩放为首帧，保持原卡牌节点，不从屏幕外重新进入。恢复后自动回到对应卡牌。

纸团拖动范围保留到视图标签高度与屏幕两侧；画布在标签上方额外预留纸团半径的空间，避免在该高度被横向裁掉。松手、取消指针、失去窗口焦点、切换视图或销毁时清除长按状态，避免纸团继续被拖动。

卡牌悬停时左上方显示“归档”，与右上方原有“丢弃”同级；触摸设备在当前卡牌上显示。左下方提供仅含背景与侧面文件书架的归档入口，与标题及视图标签左边缘、底部操作区底边对齐，不显示名称或数量；窄文件脊竖直并排放在底托上，沿用归档小记颜色，展示最多六份文件；空位用三个文件示意。悬停轻微提起文件，移出后落回底托，动效保持在背景框内。顶部“我的小记 / 已归档 / 垃圾桶”并排切换，进入已归档后隐藏缩略入口，内容区不重复展示归档标题。档案卡保留原小记颜色和装订边，去掉底部“只读 / 查看”说明，与正常斜列卡牌区分。归档时从卡牌当前实际位置缩小收窄为文件脊，放入书架，完成后提交归档并让列表补位；展开归档区时原卡牌从当前姿态收成一摞。归档预览从缩略卡放大，右上角不提供完成按钮，点击纸面或空白处、按 Escape 时回到同一缩略卡，动画中途关闭或恢复也衔接当下的纸张位置与蒙层透明度。

归档小记仅供查看，没有输入框、颜色修改或直接丢弃操作；点击“恢复编辑”后回到正常小记并打开编辑页，保留原内容、颜色与添加顺序，编辑后可再次归档。归档与垃圾桶独立，倾倒不会删除归档记录。已归档标签单独显示归档数量，正常卡牌数量与连续序号不包含归档记录；档案区可滚动访问全部归档。归档列表与预览期间始终隐藏纸团画布，预览收回时也不会短暂透出纸团。

保留 `prefs.cornerModules[账号].memo.notes` 与原有 `persist()`。正常记录没有 `deletedAt` 或 `archivedAt`；丢弃添加 `deletedAt`，归档添加 `archivedAt`，对应恢复删除该字段。倾倒先确认目标 ID 集合，动画完成后只删除仍在垃圾桶中的目标记录。取消、切换账号或关闭尚未完成的倾倒不会提交永久删除。

卡牌可连续访问全部小记。垃圾桶每页最多 12 个纸团，通过分页访问全部记录，倾倒涵盖确认时全部垃圾桶记录。WebGL／模型不可用时正常卡牌仍可编辑，垃圾桶提供列表和重试入口。减少动态效果偏好会禁用卡牌／视图过渡并缩短纸张动画。关闭弹窗释放 WebGL、监听器和动画；VAT 解码结果在当前页面内复用。

Three.js 0.160.1、cannon-es 0.20.0 随模块打包，本地加载；主站既有 Three.js 版本不变。首次新增资源约 3.7 MB（未压缩），仅打开小记时加载。静态发布需包含整个 `dist/assets/memo-paper/`。
