# 拾隅多语言

当前采用人工编写、审核和发布的语言库。LibreTranslate 已停用并移除本机运行环境及模型；服务接口不再调用外部翻译。

后台入口：`/apps/shiyu/languages`。扫描新增文案后，条目进入待翻译；填写英文并审核，发布语言包后更新前台。缺失或未审核内容使用中文。

语言库覆盖首页主题、设计与空间视图、常用、待办、小记、百宝箱、桌面伙伴、世界及公共界面。新增内容不会自动生成译文；未审核或未发布的内容保留中文。用户自定义的空间名称、收藏、笔记和待办内容不替换。

英文文案源：`editorial-en.json`。保留变量占位符，按钮和状态尽量使用 1–2 个词，必要说明不省略。

运行时所有语言读取当前 `dist` 的页面和脚本，只应用已发布语言包的 `dictionary`；不再加载发布时保存的旧版 `files`。代码更新后无需重新发布译文即可使用最新功能，新文案未发布时保留中文。资源请求保留原有版本参数并附加 `locale`，翻译服务暂不可用时回退当前源文件。各语言共用同一套 CSS。

按需加载的本地模块及其静态依赖也继承 `locale`。第三方与资源目录下的模块保持原路径。日历星期按界面语言显示，日期存储格式保持不变。

扫描同时收录后台公开配置的显示字段：模块名称与简介、主题/字体/配色/伙伴名称、空间视图名称及会员方案说明。账号数据、名单、网址、标识符和开关不进入此扫描。前台通过 `runtime.js` 在相应配置读取处应用已发布字典，不改写后台中文源数据。

维护时先运行 `node i18n/import-editorial.cjs --store "../聚合管理后台/.local/shiyu-i18n.json"` 预检；增加 `--apply` 写入本地后台并备份原字典，增加 `--publish-local` 则更新本地英文预览。导入保留语言开关、其他语言和公告，不删历史条目。线上导入或发布仍须按项目约定另行确认内容、影响和版本号。

验证：`node --test tests/i18n-current-assets.test.cjs tests/i18n-global.test.cjs`。`checks/i18n-global-ui.cjs` 使用隔离服务和模拟账号检查中英文页面；不请求真实账号写入或支付。设置 `I18N_EXTENDED=1` 可补查空间样式、图谱及各主题的常用卡片。
