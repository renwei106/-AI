# 拾隅温润楷字体交付说明

版本：v0.1 预览包 / 2026-09-16

拾隅温润楷对应原方案二，以霞鹜文楷 Regular 作为简体中文轮廓，以 Lora Regular 作为英文、数字和非中文标点。两套来源均采用 SIL Open Font License 1.1。

## 交付内容

- TTF：可安装到 Windows、macOS 和常见设计软件。
- WOFF2：已接入拾隅应用。
- SVG 字形库：44695 个可缩放轮廓符号。
- 品牌样句 SVG：打开即可查看，所有文字已经转成路径。
- ZIP：包含字体、SVG、CSS、覆盖报告、字体日志和许可原文。

## 覆盖与应用

- 总 Unicode 字符：44695 个。
- 汉字及汉字兼容区：30558 个。
- 当前拾隅应用中的 951 个不同汉字全部覆盖。
- 已加入“个性化 → 字体”，可与拾隅清雅宋、拾隅游风及系统字体互相切换。
- 不进行简繁自动转换。

本包是开源字库的重新组合与重命名版本，不是拾隅逐字原创或可独占的字体资产。覆盖范围也不等于全部 Unicode 汉字。
