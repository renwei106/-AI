# 拾隅游风字体交付说明

版本：v0.1 预览包 / 2026-09-16

## 先说结论

字体包不是一份“风格参数”，也不是浏览器看到汉字后自动把它变成同一种笔触。一个可安装字体必须同时包含：字符编码映射、每个受支持字符的轮廓、字宽与定位、字体名称和许可等数据。因此，统一风格规范负责指导生成，但最终仍要为范围内的每个汉字、字母、数字和标点保存并验收字形。

当前交付的 `拾隅游风 v0.1` 是能安装、能下载、能被网站加载的预览字体包。它把 D「游风」方向的简体中文字体与匹配的英文、数字合成到同一个字体家族，并生成了 TTF、WOFF2 和 SVG 轮廓集。它覆盖 6763 个常用简体汉字、英文字母、数字和常用标点，共 8136 个 Unicode 字符。

当前包不是完整的“所有汉字”正式版，也不是逐字原创的独占字库。中文轮廓来自 Ma Shan Zheng，英文和数字来自 Alegreya，二者采用 SIL Open Font License 1.1；衍生字体需要继续按该许可发布。如果拾隅需要可主张独占权利的原创字体，正式版必须从标准骨架、部件系统和全部轮廓开始重新设计，不能把当前开源衍生包直接称为独占字库。

## 已交付文件

- `shiyu-youfeng-v0.1/ShiyuYoufeng-Preview-Regular.ttf`：桌面安装与设计软件使用。
- `shiyu-youfeng-v0.1/ShiyuYoufeng-Preview-Regular.woff2`：网站运行使用。
- `shiyu-youfeng-v0.1/ShiyuYoufeng-Preview-glyphs.svg`：8136 个字符的可缩放轮廓符号，可转路径后自由旋转、拉伸和变形。
- `shiyu-youfeng-v0.1/ShiyuYoufeng-Preview-brand-samples.svg`：打开即可看到的品牌样句 SVG，所有文字均为真实路径。
- `shiyu-youfeng-v0.1/shiyu-youfeng.css`：网页接入示例。
- `shiyu-youfeng-v0.1.zip`：完整下载包，包含字体、SVG、覆盖报告、字体日志和许可文件。

SVG 适合做品牌标题、海报和需要自由变形的轮廓作品。网站正文仍应使用 WOFF2，桌面安装使用 TTF；SVG 轮廓集不能替代传统字体文件里的输入、换行、字距和检索能力。

## 已接入拾隅应用

- `拾隅游风 · 预览` 已成为首次使用和未明确选择字体的默认项。
- 个性化设置保留原有字体选择，用户可切到清晰黑体、经典宋体、温润楷体、雅致仿宋、几何黑体或等宽科技。
- 用户明确选择过其他字体时，升级后继续保留该选择。
- 字体设置页增加了预览包下载入口。
- 当前应用内 939 个不同汉字均能由该预览字体覆盖；现有装饰文字中的繁体“日報”已统一为简体“日报”。

## “所有汉字”正式版的边界

“所有汉字”必须先写成可验收的字符集。若按现行 GB 18030—2022 相关字型标准的规模理解，目标为 88115 个汉字（含部首/构件），远大于当前 6763 个常用简体汉字。正式版需要：

1. 锁定字符清单和现代简体字形规范，不做简繁自动替换。
2. 以已确认的识别规范建立标准骨架、部件库和笔触参数。
3. 为清单中的每个字符生成真实轮廓；部件复用能提高效率，但不能省略单字输出。
4. 自动检查缺字、轮廓方向、自交、字框、字宽、重叠和编码映射。
5. 对常用字、品牌字、易混字和复杂字做人眼盲测；未通过的字回到生成阶段。
6. 输出完整 TTF/OTF、按 Unicode 范围分包的 WOFF2，以及对应的 SVG 轮廓集。

网页端不应一次加载完整的八万多字字体。正式接入时应按常用简体、扩展区和生僻字拆分 WOFF2，并使用 `unicode-range` 按需加载；可下载的桌面包可以保留完整字体。

## 当前状态

v0.1 已经完成“可真实安装、可下载、可在拾隅切换和默认启用”的技术闭环，适合继续评审风格和实际页面效果。达到“全部 GB 18030 汉字、每字保持游风风格、可作为拾隅原创资产”的正式版仍需要单独进入大规模字形生产与验收阶段。
