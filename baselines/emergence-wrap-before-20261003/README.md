## 结构

- `scenes.js`：场景注册表、基础/进阶控件 schema、默认参数、范围及类型校验。
- `engine.js`：固定步长时钟、邻域查询、鼠标、画布渲染、暂停和销毁；模型接口 `create/update/draw`。鸟群与鱼群复用群集模型，鱼群增加水流与不同默认权重；水滴与宇宙各用独立模型。
- `app.js`：由 schema 生成面板；每个场景独立保存，进阶折叠、一键恢复、播放、重新播种、外观切换。
- `verify.cjs`：实际浏览器行为、长时数值稳定性、捕获与补充、存储、移动视口和可访问性核验。

## 本版边界

- 水滴是吸引/排斥/阻尼组成的微滴聚集模型，以低分辨率隐式表面形成融合外观；尚不是体积守恒的真实液体模拟。
- 宇宙是固定引力中心吸引无质量示踪粒子的模型，含中心软化与远端恢复；不是全粒子相互引力或科学轨道软件。
- “轻景深”只通过个体大小和明暗表现层次，运动仍为 2D；不伪装成真实 3D。
- 捕获有休息期，默认 2.5 秒后补回，支持自然消减；鼠标在面板内不影响模拟。
- 速度是全局模拟时间倍率；所有场景具备数量上限和参数校验。默认不开放任意规则脚本。
- 支持系统减少动态效果偏好（初始暂停），隐藏标签页时不推进模拟。
