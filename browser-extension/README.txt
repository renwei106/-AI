拾隅 · 网址收藏 0.1.0（本机体验版）

1. 解压此 ZIP 并保留文件夹。
2. Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
3. 开启开发者模式，选择“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
4. 从工具栏的扩展菜单固定拾隅。
5. 保持拾隅预览服务 http://127.0.0.1:4318/ 运行。打开拾隅，通过现有体验入口登录。
6. 打开普通 HTTP/HTTPS 网页，点击拾隅，选择稍后整理或空间/场景/分组。
7. 回到拾隅空间页，点击“稍后整理”查看待整理内容。

本包采用 Manifest V3。夸克、QQ、360 的具体版本尚未逐一验证。
Firefox、Safari、手机浏览器不在本版支持范围。
当前数据保存在同一浏览器本机，不是正式云端账号。清除站点数据会清除收藏。
插件只在点击时读取当前标签页标题和网址；不读取浏览历史、全部网页或原生书签。
没有自动更新功能；升级时保留安装路径，替换文件后在扩展管理页点击重新加载。
