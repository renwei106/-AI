# 拾隅小红书上线预告

交付：1 张封面 + 6 张配图，统一 1080 × 1440 px（3:4），PNG。

- `export/`：按顺序上传的七张成品。
- `总览.png`：缩略图总览，不作为正文配图上传。
- `发布文案.md`：推荐标题、正文、标签、备选标题和编辑说明。
- `index.html`：可编辑排版源文件，浏览器直接打开。
- `assets/`：真实产品截图与项目字体；没有采用抽象生成底图。
- `render.cjs`：使用本机 Playwright 和 Edge 导出；运行 `node render.cjs` 可重新渲染。
- `qa.json`：逐页文字、图片加载与主要元素边界检查结果。
- `baseline-status.txt`：制作前工作区状态。本次仅新增这个内容目录。

素材依据：本地产品现有截图、公众号首篇产品说明、`checks/official-v3/current-product.json`，以及用户本轮明确提供的上线、活动和资源规划。资源页使用文字介绍，不以虚构资源界面或伪造数量充当产品截图。

视觉：深绿与米白；封面用真实收藏空间和主题界面直接说明产品；内页分别介绍功能、亮点、资源预告与限时会员活动。中文文字保留在 HTML 中，便于继续修改。
